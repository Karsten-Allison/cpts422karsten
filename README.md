# Check Assumptions

Comments: Each `//` comment counts as a "comment". Every `/*...*/` or `/** ...*/` also counts as a "comment" no matter how many lines. Comments written inside strings don't count.

Loops: Each for, foreach, while, or do-while statement counts as a "Loop". Nested loops count separately. Loops written inside comments, strings, etc don't count.

The AntiHungarian check flags field names starting with m followed by an uppercase letter or digit, such as mInteger
